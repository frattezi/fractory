# Fractory is a configuration package, not an app

Fractory has no user interface of its own. It is the rules, skills and deterministic scripts that a Claude Code session loads to act as the factory; the human-facing surface is a fork of Agent Manager. We chose this over building a "Fractory TUI" because a second UI would duplicate Agent Manager, and keeping Fractory as plain config plus tested scripts keeps it usable from any terminal session.
